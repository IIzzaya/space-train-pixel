# 像素垂直切片 0.3

## 定位与迁移

这是新的 `space-train-pixel` 实现。原 `spacetime-train` 仓库保持不变。`docs/` 中玩法模块、设计决定、待确认问题与词汇表来自 2026-10-03 已确认设计快照，未改写规则。旧说明中的“全部尚未实现”指设计快照时点，实际代码实现范围以本页为准。

## 已实现

- 整个游戏界面统一进入 Three.js 场景：仓库／背包网格、日志、机器控件、路线、模态框、拖拽幽灵和预览均由 Mesh／纹理渲染到单一画布，不再使用可见 HTML 游戏控件。架构与诚实的软件兼容分支见[渲染架构](rendering-architecture.md)。
- 原创体素切面列车与七种物品模型。列车先渲染为低分辨率目标，HUD 使用 1280×860 逻辑分辨率合成；纹理最近邻采样。正交视锥与目标宽高比一致。
- 游戏规则、渲染、输入、界面与控制器全部迁移为 strict TypeScript。v2 存档键与数据格式不变。
- 仓库与背包之间、同一容器内部的指定格位拖放。碰撞／越界预览，原子提交；失败、拖出网格、Esc、pointercancel、失焦不丢物品。保持抓取格偏移。
- R 旋转矩形占格；旋转同步影响实际碰撞、存档、自动转移。点击物品后还可快捷转移／旋转／使用／装备，可用键盘 Tab/Enter 操作按钮。没有声称完整键盘空间摆放功能。
- 既有两条路线、自动六节点探索、FIFO 拾取、自动消耗补给、全损、备用装备、免费缓慢恢复。
- 栽培与滤水手动输入／输出，输出满停机，仓库满时领取失败不会销毁产物。
- 独立 v2 本地存档、强校验、损坏回退、储存失败提示；与旧版存档隔离。

## 测试参数，不是设计决定

仓库 8×5；帆布背包 4×3，本体 2×2；无包口袋 2×2。仓库／背包不堆叠，允许本版旋转测试。水 1×2、土豆／塑料／肥料 1×1、金属 2×1、刀 1×2。

水 +45 补水，土豆 +25 饱食；≤40 自动使用。每节点饱食 −10、补水 −14，任一归零每节点生命 −14，不叠加。节点每 3 现实秒推进一次，模拟 30 游戏秒，共 6 节点。

货运站伤害概率 32%、基础伤害 18；隧道 76%、基础伤害 40；猎刀伤害乘 0.55 后取整。全损生命 12。基地每秒生命 +0.65、饱食 +0.4、补水 +0.5，上限 100。

肥料 1→3 土豆（20 游戏秒），塑料 1→1 水（16 游戏秒）。输入上限 3、输出上限 6，整批输出放不下则不消耗原料。

初始物资与预置机器用于验收，不代表正式新手配置。铁废料只有占格与拾取用途。
