## 线上实际操作

在 GitHub Pages 仓库子路径进行了真实云浏览器操作：

- 背包土豆拖到仓库指定格；仓库内部换位。
- 拖到已有物品上拒绝落点，原物品保留；拖到网格外取消，原物品保留。
- 选中水瓶按 R，从 1×2 旋转为 2×1。
- 栽培盆／滤水器分别投料，原料从仓库减少，输入进入机器。
- 出发后不能投料／领取／再次出发；自动经历节点并安全归来。
- 投入物转为 3 个土豆、1 瓶水并留在独立输出区；领取恰好转移 1 个产物。
- 刷新保留物品布局、旋转、剩余产物和已完成探索；取消重置保留进度。
- Three.js 软件渲染分支的原始体素场景与七种物品模型可见，桌面布局无明显裁切。
