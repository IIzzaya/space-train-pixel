# 项目词汇表

本词汇表用于统一 v0.1 设计文档中的名称。它解释现有设计，不增加游戏规则。

词汇表版本为 v0.1 草案，适用于本轮设计快照。所有词条当前均为“编辑整理，待项目审定”；尚无词条批准人或批准日期。

## 核心概念

| 概念编号 | 首选名称 | 定义与适用范围 | 允许用法与易混概念 |
| --- | --- | --- | --- |
| TERM-01 | 主仓库 | 玩家在基地保管和整理物品的网格仓库 | 使用“转入主仓库”；不与机器输出区域混用 |
| TERM-02 | 出行背包 | 外出携带物品的网格容器 | 使用“背包容量”；与背包本体占格区分 |
| TERM-03 | 背包本体 | 背包作为库存物品时的对象 | 使用“丢弃旧背包本体”；本体不提供嵌套存储 |
| TERM-04 | 容纳容量 | 容器能够布置物品的网格空间 | 以格子尺寸描述；不等于物品自身占格 |
| TERM-05 | 物品占格 | 物品放入网格时占用的尺寸 | 使用“占 1×2 格”；具体旋转规则另行确认 |
| TERM-06 | 拾取 | 系统按规则把发现的战利品装入背包 | 与装备槽的主动换装区分 |
| TERM-07 | 主动换装 | 系统遇到更好装备时进行的概率性替换 | 锁定限制换装；不代表失败保护 |
| TERM-08 | 换包迁移 | 更换背包时转移全部原有内容 | 不表示允许部分迁移后丢弃剩余物 |
| TERM-09 | 全损 | 外出失败时，此次出行全部装备和物品丢失 | 不表示清空主仓库或角色永久死亡 |
| TERM-10 | 饱食度 | 反映角色食物补给状态的数值 | 达到 0 后触发渐进扣血；范围待定 |
| TERM-11 | 补水状态 | 反映角色水分补给状态的数值 | 避免用含义方向不明的“口渴值”替代 |
| TERM-12 | 普通游戏时钟 | 推进游戏日历、昼夜和普通模拟的时钟 | 与现实时间、真时资源区分 |
| TERM-13 | 真时 | 按离线现实经过时间积累的可储存资源 | 使用“积累真时”“消耗真时”；不等于世界离线运行 |
| TERM-14 | 真时模式 | 消耗真时推进列车生产的运行方式 | 普通时钟暂停；不表示角色或保险自动加速 |
| TERM-15 | 共享热量 | 基地范围共用的单一数值资源 | 与每台机器独立燃烧计时区分 |
| TERM-16 | 公共燃料槽 | 玩家指定燃料的公共输入位置 | 只使用槽内指定燃料；不等于整个主仓库 |
| TERM-17 | 机器输入区域 | 某台机器保存投入物的区域 | 同类物品限量堆叠；容量待定 |
| TERM-18 | 机器输出区域 | 某台机器保存产物的区域 | 与主仓库分开；满额行为待定 |
| TERM-19 | 时空乱流 | 后续世界变化与列车避难循环的概念 | 当前为扩展方向；不表示已实现世界事件 |
