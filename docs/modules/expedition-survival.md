# 外出与生存

本模块说明出行准备、自动探索、失败损失和角色状态。除特别标注外，正文规则均为已确认设计；数值和实现范围仍可能待定。

## 外出流程

外出存在此次出行全部装备和物品丢失的风险。角色仍会返回基地；当前规则不采用角色永久死亡。

1. 玩家选择武器、补给和背包等出行装备。
2. 玩家选择已解锁且可探索的地点。
3. 系统自动推进探索，以文字展示进程、随机事件和结果。
4. 系统结算此次外出。
5. 带回战利品后，玩家手动把物品从背包转移到主仓库。

探索途中没有逐事件的玩家选项。玩家通过出发前的准备影响推演，而不是在每个随机事件中选择分支。

路线、距离和节点间时间影响总预估时长。外出会快进，同时模拟探索与基地生产。外出快进与基地速度的关系见[时间与世界](time-world.md)。

## 拾取与主动换装

初期战利品按发现顺序装入背包。如果新物品放不下，系统丢弃新物品或把它留在原地，不替换已经携带的内容。

主动换装是独立规则。探索时发现更好的装备，未锁定的装备可能被系统概率性替换。锁定的装备槽或已装备物品不参与主动替换。

“更好”的判断、换装概率和锁定粒度尚未确定。换下的旧装备初期可以直接丢弃。背包替换另有全量内容迁移要求，见[网格库存](grid-inventory.md)。

## 外出结果

| 结果 | 已确认行为 | 尚未确定 |
| --- | --- | --- |
| 带回战利品 | 角色返回，玩家手动回仓整理 | 收益分布、具体事件与结果界面 |
| 外出失败 | 此次出行全部装备和物品丢失；角色低生命值返回 | 失败判定、返回生命值和结算顺序 |
| 其他特殊结局 | 保留发生特殊结局的方向 | 结局种类、概率及其损失规则 |

装备锁定只限制主动替换，不保护失败时的装备。后续商人保险见[成长与后续方向](progression-future.md)；当前不能按保险返还计算基础损失。

## 低成本重新积累

玩家可以跑刀或使用廉价手枪配装探索低级地图。最低限度装备的探索仍可能获得背包、装备和枪械。

该方向用于支持失败后的重新积累。尚未确定最低出发条件、初始资源和耗尽资源后的处理方式。不能据此承诺必定成功、免费赠送装备或固定收益。

## 补给占格与自动使用

食物和水以实物形式占用背包网格，并参与探索推演。达到状态阈值时，系统自动使用补给。

【待确认：自动使用阈值、使用优先级、补充值、保留策略和堆叠规则。】

物品使用后的结果按物品规则处理。瓶装水饮用后留下塑料废料，因此消费补给不一定清空原占格。具体物品转换见[基地生产](production.md)。

补给不足时是否允许出发尚未确定。自动使用补给的方向也没有确定出发校验方式。

## 饥饿和缺水

角色具有生命值、饱食度和补水状态。外出期间，补给参与这些状态的推演。

当饱食度或补水状态任一达到 0 后，系统按模拟时间逐渐扣除生命值。扣血持续到角色重新获得补给或返回基地。状态归零不会立即判为失败。

【待确认：状态消耗速率、扣血速率，以及两项同时归零时的叠加方式。】

当前没有确定额外的效率或战斗减益，也没有补充其他即死条件。

## 基地恢复

角色在基地且未探索时，生命值、饱食度和补水状态按普通游戏时间免费、缓慢恢复。玩家也可以使用对应消耗品快速补充。

初期食物和水的持续消耗需求来自外出。在基地时，饱食度和补水状态不会自动下降；基地使用消耗品仍可用于加快恢复。

真时模式暂停普通游戏时钟，因此不直接推进角色的自然恢复。离线积累真时也不等于离线恢复角色。

【待确认：三项状态的恢复速率、各类消耗品的效果和使用条件。】

医疗消耗品的使用方向已确认，医疗生产设施没有加入当前已确定的前两条生产线。
