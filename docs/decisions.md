# 设计决定

本页记录截至 2026-10-03 的有效设计决定。规则细节以对应模块为准。这里的编号仅用于文档引用，不表示开发任务、完成顺序或版本承诺。

“已确认”说明设计状态；全部系统仍未实现。后续方向单独列出，不作为首版制作清单。

## 当前有效规则

| 编号 | 已确认决定 | 规则详情 |
| --- | --- | --- |
| D-01 | 主要以界面呈现的静态 Web 前端游戏，结合网格库存、基地管理、增量成长和随机搜刮 | [设计总览](overview.md) |
| D-02 | 出发前配装并选择已解锁地点；外出途中自动推进，没有逐事件玩家决策 | [外出与生存](modules/expedition-survival.md) |
| D-03 | 归来后，玩家手动把背包战利品转移到主仓库 | [网格库存](modules/grid-inventory.md) |
| D-04 | 初期按发现顺序装包；新物品放不下就放弃，不替换背包内旧物品 | [网格库存](modules/grid-inventory.md) |
| D-05 | 外出失败时，此次出行全部装备和物品丢失；角色低生命值返回 | [外出与生存](modules/expedition-survival.md) |
| D-06 | 最低限度或廉价配装可以探索低级地点，并可能获得装备、枪械和背包 | [外出与生存](modules/expedition-survival.md) |
| D-07 | 装备锁定限制主动换装；未锁定装备可能概率性换成更好的装备 | [网格库存](modules/grid-inventory.md) |
| D-08 | 初期换下的旧装备可以直接丢弃；锁定装备仍适用失败全损 | [网格库存](modules/grid-inventory.md) |
| D-09 | 换包时自动迁移全部原有内容；无法全部放入就跳过换包，保持原状态 | [网格库存](modules/grid-inventory.md) |
| D-10 | 背包本体占格与容纳容量分开配置；简化尺寸规则为两个尺寸分别除以 2 并向上取整 | [网格库存](modules/grid-inventory.md) |
| D-11 | 地图采用抽象点到点网络；路线、距离和节点间时间影响外出预估时长 | [时间与世界](modules/time-world.md) |
| D-12 | 游戏采用 24 小时日与昼夜；外出快进同时模拟探索和基地生产 | [时间与世界](modules/time-world.md) |
| D-13 | 基地时间持续运行且可以调速；最低 1×，即 1 现实秒对应 1 游戏秒 | [时间与世界](modules/time-world.md) |
| D-14 | 整理库存和准备出发不自动暂停；指定菜单可以暂停，完整清单待定 | [时间与世界](modules/time-world.md) |
| D-15 | 离线现实时间转为等量真时，受可升级储存上限约束 | [时间与世界](modules/time-world.md) |
| D-16 | 玩家在线主动消耗真时并调消费倍率；普通游戏时钟完全暂停，列车生产独立推进 | [时间与世界](modules/time-world.md) |
| D-17 | 前两条生产线依次为食物和水；生产需要持续配方投入和生产时间 | [基地生产](modules/production.md) |
| D-18 | 初期补给的持续需求来自外出；基地饱食度和补水状态不自动下降 | [外出与生存](modules/expedition-survival.md) |
| D-19 | 食物和水占用背包网格，并在达到阈值时自动使用；阈值待定 | [外出与生存](modules/expedition-survival.md) |
| D-20 | 饱食度或补水状态达到 0 后，按模拟时间逐渐扣生命，直到补给或返回基地 | [外出与生存](modules/expedition-survival.md) |
| D-21 | 基地未探索状态下，生命、饱食和补水按普通游戏时间免费缓慢恢复；消耗品可快速补充 | [外出与生存](modules/expedition-survival.md) |
| D-22 | 1 个 1×1 格塑料废料生产 1 瓶 1×2 格水；饮用后留下 1 个 1×1 格塑料废料 | [基地生产](modules/production.md) |
| D-23 | 1 份生物肥料／粪便经过生产时间产出 3 个生土豆；烤土豆比生土豆恢复更多饱食度 | [基地生产](modules/production.md) |
| D-24 | 生土豆和烤土豆均占 1×1 格；独立厨房烤炉负责烘烤 | [基地生产](modules/production.md) |
| D-25 | 实际加工时才消耗燃料；热量是基地共享的单一数值资源，不按炉子分别计燃烧时间 | [基地生产](modules/production.md) |
| D-26 | 系统仅按生产需求转换公共燃料槽内的指定燃料，不自动燃烧主仓库其他物资 | [基地生产](modules/production.md) |
| D-27 | 机器各有独立输入输出区域；同类物品可以限量堆叠，上限待定 | [基地生产](modules/production.md) |

## 已被替代的方案

| 旧方案或理解 | 当前有效决定 |
| --- | --- |
| 每个外出随机事件都需要玩家选择 | 采用出发前准备、途中自动推进、归来后整理，见 D-02 |
| 初期直接按高低价值替换背包战利品 | 初期先发现先装入，高级策略留作升级，见 D-04、F-01 |
| 失败后保留出发武器或背包 | 此次出行全损，角色低生命值返回，见 D-05 |
| 初期把换下旧装备装入背包 | 初期可以直接丢弃；旧背包回收属于升级，见 D-08、F-03 |
| 换包时只迁移放得下的部分 | 必须迁移全部内容，否则跳过换包，见 D-09 |
| 基地库存和规划界面默认暂停 | 库存整理与配装持续计时，见 D-13、D-14 |
| 关闭页面后不结算任何离线收益 | 离线积累真时，见 D-15；没有确定离线推进完整世界 |
| 真时生产时普通时钟照常运行 | 普通游戏时钟完全暂停，见 D-16 |
| 优先建设医疗生产线 | 前两条线为食物和水，见 D-17 |
| 食物和水仅在出发时扣资源，不占格 | 补给是占用背包网格的实物，见 D-19 |
| 饥饿或缺水只产生效率减益 | 状态归零后逐渐扣生命，见 D-20 |
| 建好设施后无需原料就持续产出 | 生产需要持续配方投入，见 D-17 |
| 每台烤炉独立维护燃料燃烧时间 | 使用基地共享热量和公共燃料槽，见 D-25、D-26 |
| 机器从主仓库直接取料并把产物送回主仓库 | 机器使用独立输入输出，自动搬运未定，见 D-27 |

## 数值与实现状态

3 游戏日对应 30 现实秒、初始 2 小时真时容量、高倍率候选、煤与土豆加工时长，以及乱流间隔都保留为示例或暂定值。

具体数值状态见[时间与世界](modules/time-world.md)、[基地生产](modules/production.md)和[成长与后续方向](modules/progression-future.md)。未完成的问题见[待确认问题](open-questions.md)。
